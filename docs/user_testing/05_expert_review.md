# Alora – expert review of the study recommendations (H9)

**For:** one expert (for example an A/L Science teacher or a school career-guidance officer).
**Time:** about 30 minutes.

**What to review.** Alora gives a study plan for three made-up students. Please open each one at <http://localhost:8000/?demo=strong>, `?demo=average` and `?demo=weak`, then go to **My Recommendations**. Alternatively, use the printed screenshots. Please judge the suggestions as advice for a 15–16 year old who is about to start A/L.

| | Example A (`strong`) | Example B (`average`) | Example C (`weak`) |
|---|---|---|---|
| O/L results | All A | B and C | C and S |
| Target, district | Medicine, Kandy | Engineering, Gampaha | Medicine, Colombo |
| Plan mode | Stay on track | Close the gap (0.11) | Close the gap (0.76) |

**Rating:** 1 = very poor, 2 = poor, 3 = acceptable, 4 = good, 5 = very good.

| Example | Relevance: do the suggestions fit this student's answers and target? | Actionability: could a student actually do them? | Age-appropriateness: are the wording and amount right for 15–16? | Comments |
|---|---|---|---|---|
| A (strong) | | | | |
| B (average) | | | | |
| C (weak) | | | | |

**Questions:**
1. Is any suggestion wrong, risky or unsuitable? Which one, and why?
2. Is anything important missing?
3. The plan for the weak example also suggests backup degree areas. Is this helpful or discouraging?
